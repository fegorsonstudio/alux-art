GLOW RETOUCH WORKER (testing phase)

What it does
  Customers on the tester list order Glow Retouch on Instagram and pay. This computer then
  retouches each photo with Fegorson Studio, using your "Hanna" preset, and sends it back;
  the bot delivers it in the chat with a download button.

How to use it
  1. Double-click "Start Glow Retouch worker.cmd". A black window opens.
  2. Leave it open. Each photo takes about 30 to 50 seconds. The window says what it did.
  3. Close the window to stop. Orders wait on the website until you start it again
     (after an hour you get a Telegram alert that an order is waiting).

Good to know
  - It uses the CURRENT "Hanna" preset in Fegorson Studio. Change the preset there and new
    photos use the change.
  - You can keep using Fegorson Studio while it runs; the worker uses its own hidden copy.
  - A photo it cannot do goes to you on Telegram with the original. The customer is told a
    person is finishing it.
  - Customer photos are deleted from this computer straight after each one.
  - config.json holds this computer's private key for the website. Do not share it, email
    it or put it anywhere else.
